# Primary Computing Resource

## PACE ICE (Instructional Cluster)

HAAG's primary computing environment is the **PACE ICE cluster (Partnership for an Advanced Computing Environment — Instructional Cluster)** at Georgia Tech.

Website: https://pace.gatech.edu/

### Key Characteristics

- Free GPU and CPU access
- Shared partition across HAAG researchers
- Access tied to course enrollment
- Access granted at the start of each semester via form submission
- Managed administratively

### Current Operational State

- Basic onboarding documentation exists
- Semester-based access request process is not formally documented
- No automation for recurring access renewals

---

# Infrastructure Decision (May 2024)

In May 2024, HAAG leadership evaluated two computing options:

## Option 1: PACE Research Cluster

Not selected due to:

- Per-faculty setup requirements
- GPU/CPU resources require funding or lower-priority queue usage
- Resource segmentation by faculty group
- Funding expectations potentially unfeasible

## Option 2: PACE ICE Instructional Cluster

Selected because:

- Free GPU and CPU access
- Unified shared environment
- Simplified administrative structure
- Automatic tie to course enrollment

PACE ICE has served as HAAG’s primary computing environment since this decision.

# Known Limitations of PACE ICE

## 1. Semester-Based Access Gaps

- Access removed during semester transitions
- Must be re-requested each semester
- Creates temporary loss of computing continuity

## 2. External Collaborator Access

- No formal access process for Comp Advisors or external collaborators
- One-off requests possible but not guaranteed
- Limits oversight and collaborative supervision

## 3. Graduating & Volunteer Researchers

- Standard access removed upon graduation or role transition
- Separate ticket process required for volunteers
- Volunteer access must be re-submitted each semester
- Process undocumented

## 4. Storage Management

- Additional storage requires manual requests
- No auditing system for active vs. dormant projects
- No established storage governance framework

# Exploration of External Resources

To address semester dependency and collaborator access challenges, HAAG explored national computing programs.

---

## NAIRR (National AI Research Resource)

Website: https://nairrpilot.org/

- AI-focused pilot program
- Requires formal application
- Requires detailed resource needs assessment
- Considered as supplemental or backup infrastructure

---

## ACCESS

Website: https://access-ci.org/

- General-purpose national computing resource
- Formal application required
- Requires project-level resource estimation
- Offers persistent allocation independent of academic semester cycles
- Potential solution for Comp Advisor access

---

## Resource Requirements Survey (Ongoing)

A survey was initiated to gather:

- GPU requirements
- Storage needs
- Project-level compute estimates

Purpose:

- Support external resource applications
- Improve internal understanding of computational demand

Status: Not yet fully formalized.

# HPC Education & Professional Networks

To strengthen internal computational expertise, HAAG engaged with several networks.

---

## Campus Champions

Website: https://campuschampions.cyberinfrastructure.org/

- National HPC liaison network
- Institutional points of contact for HPC guidance
- Potential knowledge channel at Georgia Tech and affiliates

---

## CCM-Net (Computing and Communications for Minority-Serving Institutions Network)

Website: https://ccmnet.org/mentorships

- Explored for HPC mentor recruitment (unsuccessful)
- Monthly meetings proved valuable
- Facilitated networking with professionals experienced in ACCESS and NAIRR
- Currently the most productive engagement avenue

---

## CARC (Cyberinfrastructure and Advanced Research Computing)

Website: https://carcc.org/

- Hosts research-domain working groups
- HAAG proposed new groups (not advanced)
- AI facilitation and Anaconda-focused meetings identified as useful
- Valuable professional networking channel

# Strategic Need for HPC Literacy

A consistent theme across infrastructure efforts:

HAAG would benefit from stronger internal HPC knowledge.

Improved understanding of:

- GPU requirements
- Storage demands
- Runtime expectations
- Workflow structuring

Benefits:

- Better project feasibility assessment
- Stronger Comp Advisor guidance
- More informed faculty support
- More competitive external resource proposals

---

## Proposed Model

Train a small number of HAAG members to serve as:

- Internal HPC experts
- Cross-team computational advisors
- Organizational HPC knowledge anchors

This mirrors the Campus Champions model and could systematically raise baseline HPC literacy.

# Undocumented Procedures & Gaps

The following processes are not yet formally documented:

- Semester PACE ICE access request workflow
- Volunteer access request process
- Storage auditing and governance framework
- Project-level resource requirement assessment methodology
- External resource (NAIRR/ACCESS) onboarding procedures

Formalizing these processes is a priority for the next phase of HAAG’s HPC infrastructure development.
