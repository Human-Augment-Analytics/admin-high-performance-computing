# PACE Storage Audit for HPC

By Wai Lung Justin YIU | Georgia Tech | HAAG Admin | OMSCS | CS 6999 Spring 2026

---

Storage plays an important role in HPC environments, as many HAAG projects work with massive datasets for deep learning and Generative AI model training and fine-tuning. However, if there is no auditing or housekeeping of the storage, the storage may exceed its capacity quickly. Moreover, since the storage is shared across projects, a storage issue caused by one particular project could affect other projects using the same HAAG storage.

Therefore, it is necessary to establish a comprehensive auditing process for the HPC storage used by HAAG projects.

The purpose of this procedure is to describe the auditing process for HAAG project storage in PACE.

---

## 1. Method for Performing the Audit

To perform the audit, a Python script named `storage_audit_script.py` has been developed.  
The script generates the following information:

- Overall summary of the storage, including total capacity and current usage  
- Breakdown of storage usage by project  
- Last modification date of files within each project directory  

---

## 3. Distribution of the Audit Report

The report will be distributed to Director of HAAG (Bree Shi) & Head TA of HAAG (Charles Chark) on a bi-weekly base for regular review of the HPC Storage Utilization.

---

## 4. Frequency of Audit

To ensure proper storage management, the audit will be performed **at the beginning of each semester**.

Additional audits may be conducted if storage utilization approaches critical capacity levels.

--- 

## 5. Ongoing Work

At present, there is no immediate need to perform backup or data cleanup, as more than **470 GB of storage capacity remains available**.

However, moving forward, a storage lifecycle policy will be implemented. For example:

- If a project folder has **not been modified for more than 18 months**, the project owner will be notified.
- The project owner will be asked to review the data and determine whether the files should be **archived, backed up, or removed**.
- This process will help release storage capacity and maintain efficient use of shared HPC storage resources.
