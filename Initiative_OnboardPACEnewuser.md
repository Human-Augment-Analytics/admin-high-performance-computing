# Onboarding PACE, locating information, answering questions
### Thu Le
This is an initiative for the CS 8803 Management course Spring 2026

A procedure to validate that students/researchers know where to find answers regarding PACE. This procedure can create a comprehensive view of all the information locations. Main targets: users with HPC experience, current, and returning students. 

## Potential Stages/Audiences for this procedure: 
1) The team finished the PACE on-boarding training already, and they can run basic commands. Now they want to use advanced features, so they need to consult someone.  
2) The team is half way into the project, they suddenly have technical difficulty, and they need to troubleshoot. 
3) The researcher has some experience with PACE, the researcher is a returning student and needs a refresh on the main information. 

## Ideas for Slack channel (or Ed Discussion portal):
- Create a separate Slack channel for questions by users, but need to reduce redundant questions
The users should already have some fundamental understanding about HPC. 
- Approval procedure: In order to be added to the Slack Channel, the user needs to finish setting up their PACE account (can send a screenshot to admin for validation). 
- If no PACE account is available, they can show proof of finishing viewing the PACE tutorials (https://mediaspace.gatech.edu/channel/PACE/283315292). If the error they are facing is just administrative, it can easily be solved by PACE personnel in this Slack channel.
- Questions can be posted and answered here in an IT ticketing system manner (or something similar to Ed Discussion board).  
- A main post in this channel will be pinned to show the frequently asked questions (consult PACE to get this FAQs post)
- Another pinned post will show links to main materials:
Orientation workshop videos: https://mediaspace.gatech.edu/channel/PACE/283315292
PACE official website: https://pace.gatech.edu/ice-cluster/
Comprehensive instructions: https://github.com/guru-desh/Intro-To-PACE-ICE?tab=readme-ov-file

## Personnel in the private Slack channel:
- PACE personnel
- Computational Advisor 
- Researchers (need to go through approval procedure)
- Admin
