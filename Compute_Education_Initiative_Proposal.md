# Cloud & HPC Compute Education Initiative

**Syed Ahsan Subzwari | Georgia Tech | Spring 2026**

---

## The Problem

Researchers at Georgia Tech write code that works — but most have no idea how to run it efficiently on real infrastructure. They either over-provision resources (wasting money and shared capacity) or under-provision them (causing crashed jobs and lost work). There's no single, accessible guide that walks a researcher from "I have code" to "it's running optimally on PACE or AWS."

## What I'm Building

A comprehensive, plain-language reference guide that covers the **full compute workflow** for GT researchers with little to no infrastructure experience. The guide will span:

- **Profiling & bottleneck identification** — teaching researchers to measure what their code actually needs before requesting anything
- **Resource right-sizing** — translating measurements into concrete hardware requests (CPUs, RAM, GPUs, wall time)
- **Platform selection** — a decision framework for when to use PACE vs. AWS
- **End-to-end workflows** — step-by-step instructions for both PACE (Slurm job scripts, storage tiers, QoS levels) and AWS (instance selection, Spot pricing, billing safety)
- **Containerization & portability** — Docker/Apptainer basics so code moves seamlessly between platforms
- **Worked examples** — real scenarios covering deep learning training, bioinformatics pipelines, and large-memory data processing

## Who It's For

PhD students, postdocs, and faculty who have working research code but no background in HPC or cloud infrastructure. No prior knowledge of Slurm, AWS, or Docker is assumed.

## Deliverable

A single written guide that serves as both a learning resource and an ongoing reference. Researchers can read it end-to-end when getting started, then return to specific sections as needed.

## Timeline

This is my semester initiative. I will research, draft, review, and finalize the guide over the course of the term, with the goal of producing a polished, shareable document by the end of the semester.
